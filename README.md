# AudioConducker 🎚️🦆

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

A cross-platform automatic audio ducking for desktop applications.

AudioConducker automatically lowers the volume of one application when another application starts playing audio.

## Status

🚧 Under development.

## 🎯 Planned Features

- Cross-platform
    - Linux (PipeWire)
    - Windows (WASAPI)
    - macOS (ScreenCaptureKit)

- **Configurable Ducking Rules:** Smoothly manage foreground and background audio sources.
 
- **DSP Parameters Control:** Adjustable Attack, Release, and Threshold via a clean GUI.

- **Multi-rule Support:** Handle multiple application routing paths simultaneously.
